# YWpM - YoRHa Wallpaper Manager
YoRHa Wallpaper Manager is a modern, user-friendly command-line tool that helps you manage all your wallpapers on Linux. Please note that YWpM only determines when and which wallpapers to render, it doesn’t render the wallpapers itself. Instead, YWpM uses a backend. Currently, only mpvpaper is supported as a backend.
