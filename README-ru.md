# YWpM - YoRHa Wallpaper Manager
YoRHa Wallpaper Manager — это современный, удобный консольный инструмент, который помогает управлять всеми вашими обоями в Linux. Обратите внимание, что YWpM только определяет, когда и какие обои реднерить, а не рендерит обои самостоятельно. Вместо этого YWpM использует бэкенд. На данный момент в качестве бэкенда поддерживается только mpvpaper.

## Сборка

### 1. Зависимости
* cargo
* mpvpaper. Установка рекомендуется с репозиториев вашей системы или отсюда: https://github.com/GhostNaN/mpvpaper

### 2. Компиляция и сборка пакета
#### 2.1. Сборка DEB-пакета:
``` bash
cargo install cargo-deb
cargo deb
sudo apt-get install ./target/debian/*.deb
```

#### 2.2. Сборка RPM-пакета:
``` bash
cargo install cargo-generate-rpm
cargo generate-rpm
```

Установка для **Fedora / RHEL / CentOS**:
``` bash
sudo dnf install ./target/generate-rpm/*.rpm
```

Установка для **Alt Linux**:
``` bash
sudo apt-get install ./target/generate-rpm/*.rpm
```

#### 2.3. Компиляция без сборки пакета
``` bash
cargo build --release
```

### 3. Запуск сервиса
Сервис не запускается автоматически (из-за особенностей systemd). После установки необходимо выполнить:
``` bash
systemctl --user daemon-reload
systemctl --user start ywpmd.service
```

## Использование
Сервис `ywpmd` **не** добавляется в автозагрузку systemd в принципе - `systemctl enable` не сработает. Такое решение было принято после нескольких неудачных попыток заставить systemd запускать его в нужный момент. Просто пропишите автозапуск для вашей системы: `systemctl --user start ywpmd.service`. Если после загрузки показывает чёрный экран, попробуйте добавить `sleep 1`. Эта задержка чаще всего помогает. Если не помогает - смотрите `systemctl --user status ywpmd.service`.

После успешного запуска сервиса он будет показывать пустой экран. Это нормально. Сервис ещё не знает, какие обои нужно отображать. Добавьте их:
``` bash
ywpm add <path>
```

**\<path\>** - путь к папке или файлу. Для папки добавляет все обои. По умлочанию не рекурсивно. Чтобы указать уровень вложенности, используйте:
``` bash
ywpm add -r 65535 <path>
```

`65535` - максимальный уровень вложенности.

После этого можно поставить рандомные обои:
``` bash
ywpm random
```

**Примеры:**
* `ywpm set /path/to/file.png` - установить обои на текущую сессию (либо до следующей любой смены периода)
* `ywpm reset` - сбросить обои. Покажет серый/чёрный экран
* `ywpm get` или `ywpm get -v` - посмотреть текущие обои. Флаг **-v** показывает дополнительную информацию
* `ywpm list` или `ywpm list -v` - посмотреть все обои
* `ywpm remove /path/to/file.png` - удалить обои из программы. **Не** удаляет файл/папку с диска
* `ywpm clear` - удалить все обои из программы. **Не** удаляет ничего с диска
* `ywpm find-non-fitting` - Найти все изображения и видео, у которых соотношение сторон отличаеся от монитора и для которых не задан --mode. Для видео также проверяет попиксельное совпадение разрешения, так как масштабирование видео в реальном времени - недешёвая операция.

## Продвинутое использование. Опции
### -m, --mode
Режим отображения обоев. Можно задать выравнивание по вертикали (top/center/bottom), по горизонтали (left/center/right) и режим растягивания:

* `cover` - Обрезает края, сохраняет пропорции
* `contain` - Оставляет пустое место по краям, сохраняет пропорции
* `stretch` - Не сохраняет пропорции, растягивая картинку

**По умолчанию:** `center cover`

**Примеры:**

* `ywpm add /path -m 'cover right'` - Картинка будет смещена вправо и обрезана, если она шире экрана
* `ywpm add /path -m 'top contain'` - Картинка будет смещена вверх без обрезки, если она шире экрана

### -r, --recursive-level
Уровень рекурсивного поиска файлов в папке. Диапазон: `1..65535`

**По умолчанию:** `1`

## Продвинутое использование. Периоды времени
Обои или группу обоев можно установить на определённый период времени. В случае если в какой-то момент установлено несколько обоев и/или групп, выбираются случайные обои из всех установленных с равной вероятностью. Для того, чтобы задать период, существуют 3 опции: **--since**, **--until** и **--duration**. Опции **--until** и **--duration** не могут быть указаны одновременно. Если указана опция **--since**, то должна быть указана одна из опций **--until** или **--duration** - программа не позволяет задать обои навечно. Если вам всё же хочется, можете хоть на 1000 лет вперёд задать: **--duration=1000y**

### -s, --since
Начало периода с точностью до минуты. Не учитывает часовой пояс. Вы можете указать целую и дробную часть секунд и часовой пояс. Они будут проигнорированы. Такое решение принято для совместимости с основными распространёнными форматами времени.

**Примеры:**

* `14:00` - сегодня в 14:00
* `2026-06-11 12:00`
* `27 jul 2026 20:08:32 +0000` - превращается в `2026-07-27 20:08`
* `now` - текущее время
* `tomorrow` - текущее время плюс одни сутки

**По умолчанию:** `now`

### -u, --until
Конец периода с точностью до минуты. Формат тот же, что и у **--since**.

**По умолчанию:** \<не задано\>

### -d, --duration
Длительность периода.

**Примеры:**

* `30m`, `30 minutes` - полчаса
* `12h`, `12 hours` - 12 часов
* `2w` - 2 недели
* `5 month` - 5 месяцев. Месяцы считаются по 30 дней
* `1 y` - 5 год. Годы считаются по 365 дней
* `20:30` - Тут формат тот же, что и у **--since** (за исключением `now` и `tomorrow`)

## Продвинутое использование. Группы
Группа в ywpm - это, собственно, группа файлов и/или папок. С группами можно делать практически всё то же самое, что и с отдельными папками/файлами - устанавливать их через `set` (тогда выбирается случайный файл из группы), планировать на какой-то период. Но опции **--mode** и **--recursive-level** недоступны для групп. Вот все основные действия, которые можно делать с группами:

* `group-list` - Показать список всех групп
* `get-group` - Показать информацию и состав группы
* `new-group` - Создать новую группу
* `set-group` - Установить рандомные обои из группы
* `add-to-group` - Добавить файлы/папки в группу
* `remove-from-group` - Удалить файлы/папки из группы (не с диска)
* `clear-group` - Очистить группу
* `remove-group` - Удалить группу
