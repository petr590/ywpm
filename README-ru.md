# YWpM - YoRHa Wallpaper Manager
YoRHa Wallpaper Manager — это современный, удобный консольный инструмент, который помогает управлять всеми вашими обоями в Linux. Обратите внимание, что YWpM только определяет, когда и какие обои реднерить, а не рендерит обои самостоятельно. Вместо этого YWpM использует бэкенд. На данный момент в качестве бэкенда поддерживается только mpvpaper.
